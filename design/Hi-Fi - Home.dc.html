Componentes
Sidebar/nav (item ativo, hover, desabilitado), Topbar com Search e Button/primary, Card/metric ×3, Table/felinos com Avatar/monograma e Badge de status, Chips de filtro, FAB mobile 56px, TabBar 4 itens, EmptyState com checklist de onboarding.
Comportamento
Busca com debounce de 300 ms e resultados na própria tabela. Chips são filtros exclusivos entre si. Linha inteira clicável → prontuário; menu ⋯ abre ações rápidas (nova pesagem, agendar retorno). Ordenação padrão: atualizado mais recente.
API
GET /felines?sort=-updatedAt&limit=20 · GET /me/summary para os cards · 401 no refresh derruba para a Tela 01 com toast "sessão expirada" · total 0 renderiza o estado vazio.
Acessibilidade
Status sempre com texto, nunca só cor. Alvos mobile ≥ 44px (FAB 56). Tabela navegável por teclado, linha como role=row focável. Contraste mínimo 4.5:1 em todos os badges.
